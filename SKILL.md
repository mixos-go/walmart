# Walmart Marketplace API Guide

Use this skill to answer exact Walmart Marketplace API structure questions and avoid
guessing fields.

## Coverage

- Platform: Walmart Marketplace API (`https://marketplace.walmartapis.com`).
- 17 category folders under `references/api/` (Authentication & Authorization, Item,
  Price, Inventory, Order, Reports / On-request Reports, Returns, Fulfillment, Feeds,
  Rules, Settings, Utilities, Notifications, Insights, Promotion, Lag Time), 119 API
  docs total.
- Each doc has YAML frontmatter (`title`, `category`, `api_name`, `method`, `path`) plus
  structured sections: `## API Description`, `## Request Parameters`, `## Request Body`,
  and `## Response`.
- Response/request fields are flattened nested trees (parent→child via `.`), with type
  and required flags; array element schema names shown like `array<SomeSchema>`.
- Auth: Client ID + Client Secret + Signed requests (consumer id / private key via the
  Walmart signing mechanism); the reference also includes an Auth spec.

## Workflow

1. Read the request and identify the business capability (item, price, inventory, order,
   report, return, fulfillment, feed) and any explicit method/path.
2. Map the capability to a category and inspect
   `references/api/<Category>/<operationName>.md`.
3. Search `references/api/` by operation name, path segment, resource, or keyword when
   unclear.
4. Read the exact method (`GET`/`POST`/`PUT`/`DELETE` in frontmatter/body), the HTTP path
   (e.g. `/v3/items`), the Request Parameters, the Request Body, and the Response schema.
5. Do not silently substitute a nearby operation that targets a different resource shape.
6. If a schema, deprecation, or newer version is not present in the local reference,
   check the official Walmart Marketplace docs
   (`https://developer.walmart.com/doc/us/mp/us-mp-intro`) and state the gap/source.
7. Do not invent fields, enum values, required flags, or response shapes absent from the
   selected API's official schema.

## References

- `references/api/<Category>/<operationName>.md` — one clean Markdown doc per Walmart operation.
- Category folders map to Walmart Marketplace API groups (e.g. `Item Management`,
  `Price Management`, `Order Management`, `Inventory Management`).

## Update & Provenance

- Local reference is a **static snapshot**. It is regenerated by the toolchain in the
  `updskills` repo (`tools/spec_to_markdown.py`), which parses the OpenAPI 3.0 specs
  downloaded by the community SDK
  (`github.com/whitebox-co/walmart-marketplace-api`, `docs/schemas/`). To get fresher
  schemas, run that SDK's schema download step and re-run the tool rather than hand-editing.
- For agent use, prefer the official live docs
  (`https://developer.walmart.com/doc/us/mp/us-mp-intro`) for anything that may have
  changed since this snapshot (deprecations, new endpoints, policy).
