**Category:** On-request_Report_Management
**API:** Download_Report_URL

**Method:** GET
**HTTP Path:** https://marketplace.walmartapis.com/v3/reports/downloadReport

## API Description
Download Report URL

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| requestId (query) | string | Yes | Automated ID generated by system that uniquely identifies the report request. |
| Authorization (header) | string | Yes | Basic authorization header. Base 64 encodes the Client ID and Client Secret retrieved in step two of the integration steps. |
| WM_SEC.ACCESS_TOKEN (header) | string | Yes | The access token retrieved in the Token API call |
| WM_CONSUMER.CHANNEL.TYPE (header) | string | No | A unique ID to track the consumer request by channel. Use the Consumer Channel Type received during onboarding |
| WM_QOS.CORRELATION_ID (header) | string | Yes | A unique ID which identifies each API call and used to track and debug issues; use a random generated GUID for this ID |
| WM_SVC.NAME (header) | string | Yes | Walmart Service Name |
| Accept (header) | string | Yes | Only supported Media Type : application/json |

## Response
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| downloadURL | string | No | URL to be used to download the report. |
| downloadURLExpirationTime | string | No | Time till when the URL to download the report will be valid. |
| requestId | uuid | No | Automated ID generated by system that uniquely identifies the report request. |
| requestStatus | string | No | Status of report request. Possible values are RECEIVED, INPROGRESS, READY, ERROR. (RECEIVED, INPROGRESS, READY, ERROR) |
| requestSubmissionDate | string | No | Date and time on which the report request is submitted. |
| reportType | string | No | Type of report for which the request is created. Example, ITEM for Item Report. (ITEM, INVENTORY, CANCELLATION, DELIVERY_DEFECT, ITEM_PERFORMANCE, PROMO, RETURN_OVERRIDES, CPA, SHIPPING_CONFIGURATION, SHIPPING_PROGRAM) |
| reportVersion | string | No | Version of report for which the request is created. Example, v1. |
| reportGenerationDate | string | No | Date and time on which the report is generated. Attribute is available only if report is generated. |
