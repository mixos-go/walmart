**Category:** On-request_Report_Management
**API:** Create_Report_Request

**Method:** POST
**HTTP Path:** https://marketplace.walmartapis.com/v3/reports/reportRequests

## API Description
Create Report Request

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| reportType (query) | string | Yes | Specifies the report type for the request. For example, reportType=ITEM creates an Item Report. |
| reportVersion (query) | string | Yes | Version of report for which the request is created. Supported versions for each report type are currently 'reportVersion=v1' for the following reportType(s): INVENTORY, CANCELLATION, DELIVERY_DEFECT, ITEM_PERFORMANCE, PROMO, RETURN_OVERRIDES, CPA, SHIPPING_CONFIGURATION, SHIPPING_PROGRAM, FITMENT_MI |
| Authorization (header) | string | Yes | Basic authorization header. Base 64 encodes the Client ID and Client Secret retrieved in step two of the integration steps. |
| WM_SEC.ACCESS_TOKEN (header) | string | Yes | The access token retrieved in the Token API call |
| WM_CONSUMER.CHANNEL.TYPE (header) | string | No | A unique ID to track the consumer request by channel. Use the Consumer Channel Type received during onboarding |
| WM_QOS.CORRELATION_ID (header) | string | Yes | A unique ID which identifies each API call and used to track and debug issues; use a random generated GUID for this ID |
| WM_SVC.NAME (header) | string | Yes | Walmart Service Name |
| Accept (header) | string | Yes | Only supported Media Type : application/json |
| Content-Type (header) | string | Yes | Only supported Media Type : application/json |

## Request Body
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| rowFilters | array<object> | No | Row Level filters |
| rowFilters.from | string | No | Filter range start |
| rowFilters.to | string | No | Filter range end |
| rowFilters.rowFilterType | string | No | Type of the filter (rangeFilter, enumFilter) |
| rowFilters.columnName | string | No | Column on which filter has to be applied |
| rowFilters.values | array<string> | No | Enum filter values which has to be included in report |
| rowFilters.type | string | No | Type of the filter (rangeFilter, enumFilter) |
| excludeColumns | array<string> | No | Columns to exclude from report |

| requestSubmissionDate | string | No | Date and time on which the report request is submitted. |
