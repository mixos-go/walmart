**Category:** Insights_Management
**API:** Top_Trending_Items

**Method:** GET
**HTTP Path:** https://marketplace.walmartapis.com/v3/insights/items/trending

## API Description
Top Trending Items

## Request Parameters
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| departmentId (query) | string | Yes | departmentId |
| categoryId (query) | string | No | categoryId |
| limit (query) | string | No | The number of items to be returned. |
| offset (query) | string | No | The object response to start with, where 0 is the first entity that can be requested. |
| timeFrame (query) | string | No | Returns all trending items for the given time frame in days |
| Authorization (header) | string | Yes | Basic authorization header. Base 64 encodes the Client ID and Client Secret retrieved in step two of the integration steps. |
| WM_SEC.ACCESS_TOKEN (header) | string | Yes | The access token retrieved in the Token API call |
| WM_CONSUMER.CHANNEL.TYPE (header) | string | No | A unique ID to track the consumer request by channel. Use the Consumer Channel Type received during onboarding |
| WM_QOS.CORRELATION_ID (header) | string | Yes | A unique ID which identifies each API call and used to track and debug issues; use a random generated GUID for this ID |
| WM_SVC.NAME (header) | string | Yes | Walmart Service Name |

## Response
| Field | Type | Required | Description |
| --- | --- | --- | --- |
| payload | object | No |  |
| payload.totalCount | integer | No | Total count of qualified items |
| payload.items | array<object> | No | List of Qualified Items |
| payload.items.categoryName | string | No | The categories this item belongs to |
| payload.items.departmentName | string | No | The department this product belongs to |
| payload.items.isbn | string | No | International Standard Book Number |
| payload.items.productName | string | No | A seller-specified, alphanumeric string uniquely identifying the product name |
| payload.items.isTwoDayEligible | integer | No | if the item can be shipped in two days |
| payload.items.itemId | string | No | Specifies the item identifier generated by Walmart |
| payload.items.totalOffers | integer | No | Total number of item stored by seller |
| payload.items.issn | string | No | International Standard Serial Number |
| payload.items.existsForSeller | integer | No | if seller is selling this item |
| payload.items.rank | integer | No | Level of trending for this item |
| payload.items.brand | string | No | Specifies the item brand |
| payload.items.superDepartmentName | string | No | The superDepartmentName this item belongs to |
| payload.items.subCategoryName | string | No | The subCategoryName this item belongs to |
| status | string | No |  |
